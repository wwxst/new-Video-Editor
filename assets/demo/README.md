# Arcline demo media

Real-world, publicly licensed media for the built-in sample editing project. The timeline decodes
these files directly: video clips show frames decoded from the actual videos, photographs are
decoded stills, and the audio tracks show min/max envelopes decoded from the actual recordings.
Nothing in this folder is generated by FFmpeg's test sources or synthesised by SAPI.

The media folder is intentionally small: 9,826,476 bytes (9.4 MiB) of media, or 9,969,147 bytes
(9.5 MiB) including the bundled CJK font under `assets/fonts`.

draw the embedded video waveform. `market_crowd.mp4`, `ocean_cliffs.mp4` and `seagulls.mp4` are
deliberately silent, which exercises the larger all-thumbnail layout for videos without audio.

## How the derivatives were prepared

The originals are large (the Market Street video is 127 s and 76 MB at 720p), so the sample uses
Commons' own transcoded derivatives and keeps short, motion-rich sections:

1. Download the 480p VP9 derivative of each video (854×480) with `curl`.
2. Trim the selected section, scale to 640×360, force 24 fps and encode H.264 with
   `h264_qsv` from the pinned FFmpeg 9.1 LGPL build. `city_street.mp4` and `train_station.mp4` keep
   a mono 44.1 kHz AAC ambient track; the other three are encoded video-only.
3. Re-encode the piano recording and the LibriVox reading to 44.1 kHz mono 16-bit PCM WAV, with
   short fades. The narration gets a speech-band filter (+9 dB) so its waveform is clearly visible
   at timeline height without clipping.
4. Save the landscape image from Commons' 1280 px JPEG thumbnail, convert both photographs to PNG
   (the still decoder handles PNG reliably), and keep the portrait's original 1200×1600 pixels.
5. Record the SHA-256 of each result.

The repository's `scripts/demo-media.ps1` repeats steps 1–4 (network required) and writes this
folder. The script is not run by the build or by tests.

## Verification

`ffprobe` on the checked-in files:

- all five videos: H.264, 640×360, `yuv420p`, 24/1 fps; `city_street.mp4` and
  `train_station.mp4` also carry mono 44.1 kHz AAC audio, the other three are video-only;
- `mountain_lake.png`: PNG 1280×854; `studio_portrait.png`: PNG 1200×1600;
- `piano_theme.wav` and `narration.wav`: `pcm_s16le`, 44,100 Hz, mono;
- all files decode; the narration is non-silent (mean −16.2 dB, max 0.0 dB after the limiter) and
  its waveform contains distinct speech bursts and pauses.

The ignored integration test `real_demo_media_decodes` decodes a frame from `city_street.mp4`, the
`mountain_lake.jpg` still and the `narration.wav` envelope through the same libav path the timeline
uses.

## CJK font

The sample project's title and subtitle clips are Chinese. egui's bundled fonts contain no CJK
glyphs, so `assets/fonts/NotoSansSC-Arcline.ttf` is a 580-character subset of Noto Sans SC
(weight 400, 138,400 bytes) installed as the last fallback for proportional and monospace text.
Its internal family is renamed `Arcline CJK` so the subset does not present itself as the upstream
font. It is licensed under the SIL Open Font License 1.1; the copyright notice and full text are in
[`assets/fonts/OFL.txt`](../fonts/OFL.txt). Latin text keeps using egui's own fonts; only characters
outside them fall through to this subset.
